# Kimi Icon Prompt for PaperBite

请为 PaperBite 设计一个应用图标。PaperBite 的含义是“一口一篇论文”：把一篇研究论文浓缩成可快速阅读的 Markdown 精华笔记。

核心画面：
- 一张简洁的论文/Markdown 文档，右上角有一个小小的 bite mark，表达“bite-sized paper”。
- 文档内只放几条短横线表示摘要笔记，不要出现可读文字。
- 可以加入一个小书签或索引标签，暗示本地论文知识库。

视觉风格：
- 现代扁平矢量图标，边缘清晰，轻微层次感。
- 在 16px、32px、128px、512px 下都能辨认。
- 专业、克制、适合科研工具，不要卡通化。
- 居中构图，正方形画布，透明背景或简洁圆角底都可以。

配色建议：
- 纸张使用白色或微暖白。
- 文字线条使用深蓝黑或炭黑。
- bite/bookmark 使用清新的绿色作为识别点。
- 可少量加入琥珀色高光，但整体不要变成单一紫色、蓝紫渐变或过度装饰。

避免：
- 不要出现牙齿、嘴巴、人物、动物、吉祥物、真实食物。
- 不要放论文会议 logo、出版社 logo、不可读小字或密集段落。
- 不要做成常见 AI 风格的紫蓝渐变图标。

请输出一个可用于产品原型的 SVG 或高清 PNG 图标方案。
